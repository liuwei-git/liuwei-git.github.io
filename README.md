# liuwei-git.github.io

Personal learning collection, published through GitHub Pages from `main`.

- [Website](https://liuwei-git.github.io/)
- [Flow Matching & Diffusion — An Interactive Course](https://liuwei-git.github.io/flow-matching-diffusion.html)

The course contains 15 lessons, 15 interactive labs, and 30 knowledge checks.
Its scripts, styles, and fonts are embedded in the HTML, so the downloaded
course also works offline. D3 and KaTeX license notices are preserved in the
HTML. No build step is required.
